# 심명 명리 꿈해몽

미륵사 심명스님 · 와이튜브북스 『심명 명리 꿈해몽 사전』 연계 프로그램.

꿈 내용과 꿈 꾼 날짜·시각을 넣으면 꿈 상징 해몽, 그날의 간지 네 기둥과 음력, 십신·십이운성·합충 풀이, 심명 스님의 마음 한마디, 심명식 행운번호 3세트(번호마다 근거 표시)를 보여 줍니다.

- 휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 설치되고, 한 번 연 뒤에는 인터넷 없이도 작동합니다.
- 모든 계산은 기기 안에서만 이루어지며 입력한 내용은 저장·전송되지 않습니다.
- 행운번호는 재미로 보는 것이며 당첨 확률(1/8,145,060)을 바꾸지 않습니다.
